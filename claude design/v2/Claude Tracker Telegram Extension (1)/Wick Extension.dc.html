Principles for v0.1
Borrow, never brand
Inherit the host page's spacing, radii and text colors from CSS variables. No logo, no colored banner in the sidebar.
One surface, one job
Sidebar shows state. Settings holds config. Telegram carries events. Nothing appears in two places.
Fail quiet
If the DOM shape changes or the bot 401s, degrade to a dim dot and a tooltip — never break the page you're guesting on.
Contributor-shaped
Selectors in one file, notification channels behind a two-method interface — so "add Discord" is a 40-line PR.
